# 实施状态

本文记录当前代码实现范围。业务规则以[业务功能说明](../业务功能说明.md)为准，接口以[OpenAPI 契约](openapi.yaml)为准，技术边界见[架构说明](architecture.md)。部署者应按目标环境阅读[部署说明](deployment.md)。

| --- | --- | --- |

## UI-76 至 UI-80

- UI-76：为旧浏览器补充 `Object.hasOwn` 兼容，修复工作项详情 Markdown 渲染白屏。
- UI-77：工作项详情使用明确的编辑入口。
- UI-78：编辑保存或取消后返回同一记录查看页；取消不提交未保存内容。
- UI-79：详情更多菜单提供复制和删除；复制进入同类型新建流程，不复制评论、历史或独立附件。
- UI-80：附件入口与待上传文件行统一展示，上传时机和既有权限保持不变。
