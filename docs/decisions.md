## 物理设计落地

用户组权限与项目工作流用经服务校验的 JSON 字段保存，随所属记录版本更新；三类工作项明细保持独立关系表。成员移交、工作项写入及迭代结束共用项目行锁；最后管理员保护通过事务锁定用户组序列化。通知采用数据库持久事件和提交后投递，不引入消息队列。具体映射见 data-model.md。

本地开发工作区与远程版本库可独立管理。部署目标、TLS 证书及异地备份策略由各部署者按自身环境配置。便携归档可能含环境密钥、数据库、附件和 TLS 私钥，应限制访问并通过加密渠道迁移。


## UI-17（已决，2026-10-20）

依据本次用户要求，取消工作项流转的通知成员、原因及未完成子任务确认，合法状态边与权限/版本校验保留；流转必须有至少一位可写成员处理人。多处理人均获得原负责人权限与通知，成员工作量每人计入一份，项目总计去重。为兼容旧表单/API，保留 assignee 主处理人列；修改该单选字段时替换集合，未改变时保留集合。历史评论状态仅从已有审计恢复，缺少证据时显示未知。回退迁移前须备份，避免额外处理人丢失。

D-06（历史方案，已被UI-37/UI-38替代）：项目文档采用纯前端基础预览，后端不转换。DOCX=docx-preview，XLS/XLSX/CSV=SheetJS CE，PPTX=pptx-preview，PDF=PDF.js，TXT=文本。按格式加载，私有原件不交给外部Office服务；旧DOC/PPT/OpenDocument/RTF保留导入下载。该依赖组合已经移除，当前以File Viewer为准。

### UI-29 本机草稿

工作项新增保存草稿按钮。采用当前浏览器IndexedDB保存字段和未上传文件，按账号、项目、类型隔离；草稿不参与列表、状态流转和通知，不上传服务端，不支持跨浏览器同步。该选择避免新增未定义的业务草稿状态。用户主动保存后下次新建恢复，创建成功清理，取消保留已保存版本。

### UI-36 重新确认纯前端预览边界

DOCX、XLS/XLSX、PPTX及PDF使用各格式浏览器解析库，不采用统一Office远程iframe。DOC/PPT保留原件下载，不宣称已支持本地渲染。SheetJS支持XLS，不能把Excel二进制旧格式与DOC/PPT一起判断为不支持。开发缓存隔离之外，预先优化所有已知Office组件，避免按需优化导致依赖URL失效。具体用户文件仍需原件或可复现样本才能区分加密、损坏与库兼容性，不以组件模块HTTP200等同内容预览成功。

### 纯前端通用Office候选（调研，未接入）

用户要求常见doc/docx/xls/xlsx/ppt/pptx。现有组件组合未覆盖doc/ppt，这不代表纯前端无法实现。候选flyfish-dev/file-viewer提供浏览器端六类格式解析、Worker/WASM和按格式加载；其二进制PPT公开引擎带水印，去水印需商业授权，不能把整体Apache-2.0当作所有引擎的许可。https://github.com/flyfish-dev/file-viewer/blob/main/docs/guide/formats.md

ONLYOFFICE常规DocumentServer为服务端方案，不符合当前纯前端要求。第三方onlyoffice-browser将OnlyOffice与x2t WASM放在浏览器，需独立来源iframe，不等同官方轻量SDK，尚未测量首次下载和内存，不承诺具体数值。https://github.com/agentbridges-ai/onlyoffice-browser

其他候选office-open-xml-viewer提供实验性旧格式插件，明确为窄子集，不能直接承诺常见旧文档均兼容。https://github.com/yukiyokotani/office-open-xml-viewer

（历史调研结论，已由 UI-37/UI-38 完成替换。）统一纯前端候选的真实六格式样本、资源与授权验证已转为当前File Viewer验证范围；不要根据本段的旧“尚未接入”描述判断现状。

### UI-37 已采用统一纯前端预览

UI-37初次采用Full，现由UI-38按需裁剪替代。此前UI-36候选及doc/ppt下载限制已被此次实现替换；不引入ONLYOFFICE/服务器转换。项目文档导入仍使用21种扩展名；工作项附件另有独立扩展名清单，包含压缩包、视频、图片和绘图格式（见 `attachment-formats.md`）。预览依赖本地Worker/WASM/字体，已保留PPT水印和上游NOTICE。注册格式不等同用户所有原件均兼容，验证报告分别列真实测试范围与白名单范围。

### UI-38：预览格式与资源裁剪（已实现）

标准@file-viewer/react 3.2.2搭配word、spreadsheet、presentation、pdf、mindmap、image、text独立渲染器；Vite formats使用frontend/document-preview-formats.json的21项清单，不加载Full或preset。前后端白名单及完整清单由sync:document-formats同步。只发布Office/PDF所需资产，保留LICENSE/第三方NOTICE及旧PPT水印；predev/prebuild清除旧生成资源，保留Vditor。移除格式不再允许新导入，历史原件和下载不删除。无接口路径、表结构或后端转换变化。

## UI-46 / D-04：目录范围

采用Document自关联和folder类型，复用权限/审计/版本/软删除；目录默认支持嵌套，历史文件留根目录。为避免隐式数据删除，非空目录拒绝删除；首版不提供移动/重命名/目录上传/级联删除。旧Markdown内容保留可编辑，仅关闭新建入口与新建正文API。

### UI-51 项目字典与表单精简

UI-51/C-04：四类字典使用同表不同project/kind，复用现有优先级FK避免不必要数据重建；默认模板在创建时复制，不持续同步；已引用字典项采用停用而不删除。移除表单字段保留历史存储和API兼容。旧自由文本环境迁入项目字典，迁移恢复依赖事前数据库备份。

### UI-52 状态与工作流配置

UI-52/C-05：状态允许新增/删除后，使用pending/completed/cancelled显式语义，初始状态与展示顺序独立。引用中的状态禁止删除或变更类别，避免破坏历史与完成统计；可先通过已配置路径流转走工作项再删除无引用状态。默认模板复制而非持续引用。保存以整体JSON版本控制三类状态与路径，不支持条件表达式/审批节点。

### UI-54 语义配色与工作流菜单

UI-54：仅补齐默认蓝色，不覆盖非蓝色及审计中可确认的手动蓝色；旧创建时显式选蓝色与默认蓝色无法从历史记录完全区分。建议颜色只作用于创建，已有编辑保留保存颜色，手动改色优先于名称联想；项目与默认模板依然独立。


DEV-01：清理只删除确认无引用的旧预览样式/常量，不删除迁移或历史兼容字段、不卸载项目外的软件。大数据暴露的关联下拉截断与逐行查询已修复；模拟数据使用既有服务层、独立批次和仅命令进程内的历史时钟，不为造数开放后门接口。


### UI-56 重新激活范围
“结束”以没有已启用下一节点判定，而非固定状态代码或仅completed类别；未完成按已有category=pending定义，包含初始状态，排除当前状态。复用transition接口增加显式reactivate标志，普通流转规则不变，避免把临时重新激活操作保存为新的工作流连线。
