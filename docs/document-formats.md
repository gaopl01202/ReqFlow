# 导入与预览格式清单

File Viewer 3.2.2 按需渲染器，21 个导入扩展名。此表为组件内置可尝试预览的白名单，不代表所有文件都能完整还原。Office、XMind等实测范围见 verification.md。

资源本地部署，按格式加载，不使用后端转换。旧PPT公开引擎保留上游水印。

| 组件格式组 | 扩展名 |
| --- | --- |
| Word OpenXML | `docx` |
| Word Binary | `doc` |
| PowerPoint 97–2003 | `ppt` |
| PowerPoint OpenXML | `pptx` |
| Spreadsheet | `xlsx`、`xls`、`csv` |
| PDF | `pdf` |
| Mind Map | `xmind` |
| Image | `gif`、`jpg`、`jpeg`、`bmp`、`png`、`svg`、`webp` |
| Markdown | `md` |
| Code and Text | `txt`、`json`、`xml`、`log` |
