# 验收与验证

本文件记录项目的验证范围与推荐检查项。历史运行日志、生产环境状态、服务器信息和本机凭据不纳入公开源码。

## 验证范围

- 后端：Django 系统检查、数据库迁移一致性、服务层规则、权限边界、事务回滚、并发冲突、通知及审计行为。
- 前端：Prettier、TypeScript 类型检查、Vite 生产构建和 Chromium 端到端工作流。
- 契约：OpenAPI 生成与校验、前端生成类型同步。
- 数据恢复：使用隔离环境检查数据库及附件的备份、恢复与完整性。

## 在本地运行

按 [README](../README.md) 安装依赖并配置本地数据库。运行后端测试与静态检查，再在 `frontend/` 执行格式、类型和构建检查；端到端测试应使用专用测试数据库，避免污染日常开发数据。

项目包含测试与验收辅助脚本。测试账户、运行日志、截图、数据库转储及其他运行产物应留在本机忽略目录中，不应提交到版本库。

## 当前限制

测试通过情况取决于运行环境和依赖服务。交付前应在目标环境重新执行适用检查，并记录命令、结果及未执行项；本文件不表示任何特定生产环境已通过检查。
