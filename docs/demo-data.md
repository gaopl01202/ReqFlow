# 模拟数据

`seed_demo` 只允许在本地开发模式运行；生产配置会拒绝执行。生成的数据通过现有业务服务写入，使用独立批次标识，不覆盖现有业务记录。运行前备份开发数据库和附件。

```sh
PGUSER=reqflow PGDATABASE=reqflow .venv/bin/python backend/manage.py seed_demo --actor <现有系统管理员账号> --batch <批次名>
```

重复执行相同批次及参数时会补齐未完成项目，不重置已有账号密码。参数不一致或账号、项目编码冲突时命令会拒绝执行。使用 `--verify-only` 可检查批次而不写入数据：

```sh
PGUSER=reqflow PGDATABASE=reqflow .venv/bin/python backend/manage.py seed_demo --actor <现有系统管理员账号> --batch <批次名> --verify-only
```

模拟内容覆盖项目成员、需求/任务/缺陷、迭代、评论、通知和附件等常用场景，并复用正常的服务层规则、权限、编号及审计流程。图片和文档样例为合成测试内容，不应使用真实业务资料。命令生成的账号凭据、批次摘要、数据库备份及附件都属于本地运行数据，应保存在被 Git 忽略且权限受限的位置，不得提交或外发。

模拟时间由命令进程内的时钟生成，不修改系统时间；本功能不改变数据库结构。中断后可使用同批次参数续跑并重新校验。需要撤销时恢复运行前的数据库与附件备份；不要物理删除仍有业务引用的数据。
